# OctoAcme Project Management Docs

## Overview
OctoAcme uses an iterative, role-driven, and artifact-based approach for cross-functional project management. Projects progress through a lightweight lifecycle (Initiation -> Planning -> Execution -> Release -> Retrospective) with clear roles, defined artifacts, and regular cadences for alignment and decision-making. These docs describe core workflows, templates, and checklists to help teams plan, deliver, and continuously improve.

## How to use these docs
- Start with the Project Management Overview for a high-level introduction.
- Use the Project Initiation and Planning guides to create your one-pager, backlog, and release plan.
- Follow Execution & Tracking and Release & Deployment for day-to-day delivery and release steps.
- Maintain a Risk Register and review it regularly per the Risk Management guidance.
- Capture learnings in Retrospectives and track action items as issues in the project repo.
